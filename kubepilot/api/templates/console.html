Run analysis

Queues a read-only job: workload snapshot (pods / deployments), audit rules, optional OpenSearch log samples when configured, metrics samples, then an LLM summary stub. Restrict to one or more namespaces, or leave namespaces empty to scan the whole cluster.

Redis + worker required. The API only enqueues jobs. Start Redis, then in another terminal (same repo, same .env): python -m arq kubepilot.worker.worker.WorkerSettings. If status stays pending, the worker is not running or KUBEPILOT_REDIS_URL does not match the API.

Empty = all namespaces. Combine an app namespace with kube-system (or others) when you want related control-plane context in the same run.
